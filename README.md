# Second Take（第二条）

**AI 成片之后的「第二条工作台」** · 产品方案

---

## 这是什么

一个面向小影 AI 成片用户的轻量产品原型：把 AI 的产出从「一个成品」换成「一份只带三个旋钮、可以指哪改哪的草稿」，并把每次修改沉淀成个人风格档案，让第二条视频不再从零开始。

## 两个入口

| 文件 | 说明 |
|---|---|
| [`index.html`](index.html) | 可交互原型，8 屏，支持点击切屏（需要 JavaScript） |
| [`static.html`](static.html) | 无脚本静态流程版，8 屏纵向排开，任何环境可看，可直接打印成 PDF |
| [`doc.pdf`](doc.pdf) | 产品说明文档（5 页，覆盖 Q1–Q6） |

> 如果 `index.html` 打开后点击没反应，通常是运行在没有脚本权限的预览器里 —— 换用 `static.html`，或用 Chrome / Edge 直接打开。

## 本地查看

下载仓库后双击 `index.html` 即可，无需安装、无需联网、无需登录。

## 演示路径

`1 → 2 → 5 → 6 → 8`：完成页进入 → 确认风格 → 调三个旋钮 → 指哪改哪 → 拿到成片与下一支入口。

异常分支：第 4 屏（加载超时降级为 15 秒快剪版）、第 7 屏（素材不足降级为拼图模式）。
